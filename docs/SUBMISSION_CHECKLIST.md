## 1. Challenge Eligibility Requirements

- [x] **Open-Weight or Open-Source AI Core**:
  - Uses Meta's open-weight **Llama 3.2** (3B) and Google's **Gemma 2** (2B) running locally via Ollama.
  - Zero proprietary cloud APIs (OpenAI, Anthropic) required for operation.
- [x] **Theme Interpretation (Ghost in the Machine)**:
  - Channels the spirits of computing history (Ada Lovelace, ancient Unix Daemons, Segfault spectres).
  - Features a possessed terminal console, a code bug Exorcism Altar, and an interactive digital Ouija board.
- [x] **Why Open Innovation Matters**:
  - Explains how local inference enables the app to run completely in the dark (with no internet), protects confidential code tracebacks from cloud harvesting, and eliminates recurring token fees.
- [x] **Automated Test Suite**:
  - 12 comprehensive unit and integration tests passing in Pytest (`pytest tests/ -v`).
- [x] **Frontend Production Build**:
  - React 18 + Vite builds with zero errors (`npm run build`).
- [x] **Self-Contained Web Audio Synthesizer**:
  - Emits ambient chimes, whispers, and static using browser Web Audio API without external audio file dependencies.
- [x] **Open Source License**:
  - MIT License included in `LICENSE`.
- [x] **Docker Compose Configuration**:
  - `docker-compose.yml`, `backend/Dockerfile`, and `frontend/Dockerfile` provided for instant containerized deployment.
